# ESP32 Wokwi Simulation

This project contains an ESP32 circuit simulation developed and tested using Wokwi.

## Project Overview

The simulation is used to verify the basic operation of the ESP32 circuit before hardware implementation.

## Files

* `diagram.json` – Contains the Wokwi circuit components and connections.
* `sketch.ino` – Contains the ESP32 Arduino program.
* `libraries.txt` – Contains the libraries required for the simulation.

## Simulation

The circuit can be simulated using Wokwi.

The ESP32 circuit was simulated and tested using Wokwi.

[▶️ Open Wokwi Simulation(https://wokwi.com/dashboard/projects)

## Hardware

* ESP32
* LED
* Push Button
* Resistor

## Software

* Arduino IDE compatible ESP32 code
* Wokwi Simulator
